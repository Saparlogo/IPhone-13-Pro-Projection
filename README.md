# iPhone 13 Pro: Interactive 3D Teardown

**Designed and built by SHIRIYEV · Turkmenistan**

An interactive 3D engineering teardown of the iPhone 13 Pro that runs in the browser. Take the phone apart in three explode levels, inspect all 30 components, hide or isolate parts, and put it back together.

## Open it
- **Desktop:** `index.html`
- **Phones (iPhone and Android):** `mobile.html`. Phones are sent there automatically. Add `?desktop` to the address to keep the desktop layout.
- **Install like an app:** on iPhone, open it in Safari, then Share → Add to Home Screen. On Android, in Chrome, tap Install app. It works offline after the first visit.

## Controls
| Desktop | Phone |
|---|---|
| Drag to rotate, right-drag to pan, scroll to zoom | One finger rotates, two fingers zoom and pan |
| Click a part to select it | Tap a part to select it; double-tap to focus |
| E explode · A assemble · Space pause · 1–3 level | Explode button, L1–L3, slider |

## About the model
The outer shape matches Apple's published size (146.7 × 71.5 × 7.65 mm). Internal parts are approximations placed from Apple's specifications and the iFixit teardown, and each part is labelled *Dimension-matched* or *Approximate*. Built with Three.js (MIT licence).
